# 2.1 From Jacobs to Quantification: The Conceptual Evolution of Urban Vitality

## Overall Logic
```
Jacobs (qualitative, normative) → Lynch (organism, performance) → Maas/Montgomery (emergent property) → Landry (holistic interplay)
    → big data makes UV "observable" → two proxy traditions emerge
    → indices conflate supply/demand → this conflation is the root problem [C4]
```

### P1: Theoretical Roots (L110-139)
**Core argument**: UV has a rich qualitative lineage that defines vitality as emergent and holistic, not reducible to single metrics.

**Logic**:
- Jacobs (1961): direct observation → normative vision → "how cities work in real life" → four generators (tangible carriers)
- Lynch (1981): organism analogy → performance dimensions → morphology as carrier
- **Pivot**: both assign UV a "carrier" (generators / morphology) → makes it tangible but bounded
- Maas (1984) + Montgomery (1998): sociological turn → UV as emergent property → "sense of place" / "life force"
- Landry (2009): holistic → social + economic + physical interplay → multidimensional

**Callbacks**: Sets up [C4] supply-demand framework by showing UV has always had a "physical carrier" (supply) and "emergent life" (demand) duality.
